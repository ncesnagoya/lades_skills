# 機能設計書 / Functional Design

## 全体アーキテクチャ
- 機能ごとのモジュール構成 / 依存関係

## メモリマップ・リンカ配置
- ROM/RAM/SRAM 等の領域とアドレス
- ロードアドレス / エントリポイント
- スタック・ヒープ・DMA 領域

## クロック / 電源
- クロックツリー、PLL 構成、動作周波数
- 電源ドメイン（必要なら）

## 割り込み設計
- 割り込みコントローラ（GIC/NVIC 等）と割り込み源の割り当て
- 優先度、ネスト、ハンドラの対応

## ペリフェラル / レジスタ
- 使用ペリフェラルと主要レジスタ設定
- DMA を含むデータフロー

## ブート / 実行モード
- ブートフロー（ブートローダ → アプリ等）
- 特権レベル / 実行モード遷移、状態遷移図
