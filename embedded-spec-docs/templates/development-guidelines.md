# 開発ガイドライン / Development Guidelines

## コーディング規約
- 言語 / 規格（例: C11 / C++ など）
- フォーマッタ（例: clang-format, 設定の場所, タブ幅など）

## 命名規則
- 関数 / 変数 / 型 / マクロ / レジスタ定義

## メモリ・リンカ・割り込み・並行性の規約
- リンカスクリプト変更時のルール
- 割り込みハンドラの書き方、クリティカルセクション
- DMA / キャッシュ / アライメントの扱い
- volatile / メモリバリアの方針
- ※ レビュー観点の詳細はスキルの `references/embedded-checklist.md` を参照（正しさ観点の母体）

## 検証規約
- 実機・SWD での確認手順
- ビルド警告の扱い（警告ゼロを必須とするか等）

## Git 規約
- ブランチ / コミットメッセージ / レビュー
