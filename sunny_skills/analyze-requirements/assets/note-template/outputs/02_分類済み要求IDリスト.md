原文を見る場合は `REQ-ID` でそこへ戻る。
下位分類は §4 の照合の組の単位になる。

| REQ-ID | 記述区分 | 主分類 | 下位分類 | 分類上の注記 |
|---|---|---|---|---|

`分類上の注記` 欄が `削除` の行は、原本改訂で削除された要求である。

集合の確認: `REQ-ID` 集合 ＝ §1 の集合（重複 0 ／ 欠落 0。両方から `削除` の行を除く）
件数: 全 n 件

主分類別: R1 a 件 ／ R2 b 件 ／ R3 c 件 ／ R4 d 件
