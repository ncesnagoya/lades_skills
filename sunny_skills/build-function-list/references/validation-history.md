## 射程外

次の 3 つは本スキルの射程外である。

1. QA の**回答**の内容を機能 doc へ反映する手順。本スキルは `outputs/06` から作る経路だけを持つ。
   起票された `Q-xxx` を論点へ対応づけるところまでは、工程 9 が持つ。
   回答によって機能の入出力・振る舞い・状態が変わる場合は、本スキルの射程外である。
2. 原本が改訂された場合に機能リストを直す手順。同じ理由で持たない。
3. 解析ノートの作成と更新。`analyze-requirements` スキルの範囲である。

1 と 2 の場面に当たった場合、人間へ報告して判断を仰ぐ。本スキルの手順で進めてはならない。
