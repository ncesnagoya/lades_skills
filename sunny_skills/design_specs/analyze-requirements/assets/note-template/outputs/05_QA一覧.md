起票済みと未起票を同じ表に並べる。理由: 表を分けた場合、未起票の行を読み手が見落とす。
未起票の行に `Q-ID` を採番してはならない。理由: 採番は QA 台帳の責任である。
未起票の行の `Q-ID` 欄には `未起票` と書く。元の `I-xx` または `A-xx` は `元の論点` 欄に書く。
回答の内容をここに持ってはならない。起票済みの行は `doc` 列でリンク先を指すだけにする。
未起票の行は 1 論点につき 1 行とする。
起票済みの行は、QA 台帳が発行した `Q-ID` の単位に合わせる。
1 つの `Q-ID` が複数の論点を覆う場合、`元の論点` にすべての ID を読点で並べる。
例: `A-01, A-02`。集合の確認では、並べた ID を 1 件ずつ数える。
理由: 起票の単位を決めるのは QA 台帳であり、本スキルではない。
複数の論点を並べた行の `状態` は、次のとおり決める。
すべての論点が `確定` なら `確定`。すべてが `未決着` なら `未決着`。
混在する場合は `一部確定` とし、残っている論点を括弧で添える。
例: `一部確定（A-02 の再試行回数が未決着）`
`状態` 欄は、起票済みの行では `未決着` / `一部確定` / `確定` の 3 語のいずれかとする。
補足は括弧で添えてよい。
未起票の行はこの規則の対象外とし、`起票候補: ` に続けて尋ねる文を書く。題名や要約を書いてはならない。
`I-xx` 由来の行は、取り決めた読みを述べ、その認識でよいかを尋ねる形とする。
`A-xx` 由来の行は、原文に無い値または振る舞いを尋ねる形とする。
更新の手順は `analyze-requirements` スキルの `references/maintenance.md` にある。
