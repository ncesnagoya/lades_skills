### 分け方

| 分類 | 意味 | 扱う段 |
|---|---|---|
| 文書 | 全体フローの文書の欠陥。決まりが無い、曖昧、または記録と食い違う。文書を直さずに skill だけで補うと、文書と skill が食い違う | B-2 |
| skill・ツール | 文書に決まりはある（または B-2 で入る）が、実行で漏れた、または確かめ方が目視だけだったもの。skill の手順か、`work/tools/` のツールで防げる | B-3・B-4 |
| 両方 | 文書で決まりを足し、そのうえで skill・ツールで確かめるもの | B-2 の後に B-3・B-4 |
| 文書は対応済 | V2_single_reuse の作業中に、人間の指示で文書へ入れたもの。B-2 では直さない。skill には入れる | B-4 |

- 「種類」の列は、指示の 3 区分のどれに当たるかを示す: **外れ**（手順から外れた）／**迷い**（判断に迷った）／**完了条件**（完了条件を確かめにくかった）。
- 「人間が決める」と書いた行は、決まりの中身を Claude が決めてよいものではない。判断は 2026-10-05 に受けた（下記「人間の判断」）。
